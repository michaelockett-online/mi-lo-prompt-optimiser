# MI.LO Prompt Optimiser

MI.LO designs, improves and reviews prompts for AI models, agents and repeated workflows. It includes one skill and a detailed operating reference. It does not need an account, connector or external service.

## Use in Claude

Once installed, ask Claude to improve a draft prompt or create a reusable prompt from an idea. In Claude Code, invoke the skill directly with `/mi-lo-prompt-optimiser:mi-lo-prompt-optimiser`.

To install in Claude Code:

```
/plugin install mi-lo-prompt-optimiser --marketplace michaelockett-online/mi-lo-prompt-optimiser
```

For other ways to install from the public GitHub marketplace in Claude, see the [repository README](https://github.com/michaelockett-online/mi-lo-prompt-optimiser#install-in-claude).
